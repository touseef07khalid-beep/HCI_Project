# Website Behaviour Tracker

This project tracks how users interact with a webpage. It records clicks, mouse movement and scrolling, then shows the results on a live dashboard.

## Features

* Click markers and click heatmap
* Mouse path and cursor points
* Scroll depth tracking
* Dead click and rage click detection
* Element visibility tracking
* Engagement score and live statistics
* Session replay
* Event log
* Export tracking data as JSON or CSV

## How to Run

1. Download the HTML file from this repository.
2. Open it in your browser.
3. Interact with the demo page and watch the dashboard update.
4. Use the controls to view the results and export the data.
